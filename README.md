**Отчёт:** [report/report.pdf](report/report.pdf)

## Постановка

−Δu = f в области D, u = φ на границе γ, где f = 1, φ = sin(x + y).

D — часть квадрата {−2 < x, y < 2}, лежащая вне окружности x² + (y − 2)² = 1
(квадрат с вырезанным нижним полукругом).

Метод фиктивных областей: задача решается во всём квадрате П = (−2, 2)², в полукруге
добавляется штраф 1/ε², ε = h². Площади пересечения ячеек с областью вычисляются точно.
Пятиточечная разностная схема, метод сопряжённых градиентов с диагональным
предобуславливанием, критерий остановки ‖w⁽ᵏ⁺¹⁾ − w⁽ᵏ⁾‖_E < δ = 10⁻⁸.

## Сборка и запуск

```bash
make                                   # seq, omp, mpi, hybrid (g++/mpicxx, -O1)
./seq 80 80                            # M N [delta=1e-8] [файл решения]
OMP_NUM_THREADS=4 ./omp 400 600
mpirun -np 4 ./mpi 400 600
OMP_NUM_THREADS=4 mpirun -np 2 ./hybrid 800 1200
```

Аргументы всех программ: `M N [delta] [файл решения или -]`. Программа печатает число
итераций и время. У `seq` есть дополнительные аргументы:

```bash
./seq 80 80 1e-8 - trace.txt           # журнал: k, ||w(k+1)-w(k)||_E, J(w(k)), ||r(k)||_E
./seq 80 80 1e-8 - trace.txt ref.txt   # + ошибка ||w(k)-ref||_E и _C по узлам D
```

## Тесты

```bash
make test        # на своей машине может понадобиться MPIRUN="mpirun --oversubscribe" make test
```

32 проверки:

1. площади и коэффициенты схемы (сумма площадей по ячейкам = π/2, сравнение с численным
   интегрированием, значения Q и F в разных типах ячеек);
2. разбиение на домены (покрытие без пропусков, размеры отличаются не более чем на 1,
   отношение узлов в [1/2, 2], 384 конфигурации);
3. тестовая задача с точным решением u = sin(x + y) (сборка с `-DTEST_EXACT`):
   второй порядок сходимости;
4. метод сопряжённых градиентов: монотонное убывание функционала J, выполнение критерия
   остановки, число итераций;
5. совпадение решений и числа итераций у seq, OpenMP (1/4/16 нитей), MPI (1/2/4/6 процессов)
   и гибридной версии на сетках 80×80 и 37×53.

## Расчёты на IBM Polus

```bash
bash scripts/polus_all.sh              # залить, собрать, поставить в очередь LSF, дождаться, скачать
python3 scripts/collect.py             # results/polus -> report/tables, графики ускорения
python3 scripts/plot_convergence.py    # графики сходимости и ошибки
cd report && xelatex report.tex && xelatex report.tex
```

Каждое задание выполняется на узле эксклюзивно (`bsub -x`) три раза; в таблицы идёт
наименьшее время.

## Основные результаты

| Сетка | Итераций | Последовательная | Лучшее ускорение |
|---|---|---|---|
| 400 × 600 | 1499 | 11.7 с | MPI, 16 процессов: 19.0 |
| 800 × 1200 | 2892 | 78.4 с | MPI, 32 процесса: 33.6; MPI+OpenMP 4×8: 30.3 |

Приближённое решение сходится в D с первым порядком по h (ограничение метода фиктивных
областей у криволинейной границы); в тесте с точным решением схема даёт второй порядок.
